# بصيرة — نطاق المنتج الأساسي V1

## هوية المنتج

بصيرة منصة تعليمية عربية خفيفة وليست نظام إدارة مدرسة تقليدياً. يوجد مدير واحد للمنصة، ومدرسون مستقلون، وطلاب مستقلون بحساب موحّد لكل طالب.

## المسار الأساسي

المسار الأساسي هو المنتج الذي يتحمل كامل أولوية التنفيذ والأداء والاختبار:

1. المدرس يملك مواده التعليمية فقط.
2. كل مادة تحتوي على مجموعات طلابية متعددة ووحدات مرتبة.
3. كل وحدة تحتوي على دروس مرتبة.
4. أعلى صفحة المادة إعلان رئيسي واحد قابل للتحديث، ثم تظهر الوحدات والدروس.
5. الطالب لا يرى مادة أو مجموعة إلا من خلال عضوية نشطة أنشأها صاحب المادة.
6. يمكن أن يكون الطالب نفسه عضواً لدى أكثر من مدرس من دون إنشاء حساب مكرر.
7. المدرس يرى جميع مجموعات مواده ولا يرى بيانات أو محتوى مدرس آخر.
8. المدير يدير الحسابات والإعدادات العامة ويملك صلاحية رقابية كاملة.

## الحسابات والانضمام

- رمز الدخول سر خاص بالحساب ولا يُستخدم مطلقاً لإضافة الطالب إلى مجموعة.
- لكل طالب معرّف انضمام مستقل، عالي العشوائية، قابل للتدوير.
- تظهر قيمته الكاملة مرة واحدة عند الإنشاء أو التدوير، ولا تخزن كنص قابل للاسترجاع.
- إدخال المدرس لمعرّف الانضمام داخل مجموعة يربط الحساب الموجود ولا يكشف قائمة الطلاب أو أسرارهم.
- إنشاء طالب جديد يعرض رمز دخوله مرة واحدة، ثم يخزن النظام وسيلة تحقق فقط.
- الملاحظات الخاصة بالاتصال أو الدفع تخص المدرس صاحب العلاقة والمدير فقط.

## المحتوى والتقييم

- مادة ← مجموعات ووحدات ← دروس.
- الدرس إما محتوى مباشر أو أجزاء بمستوى واحد، ولا يخلط بينهما.
- الملفات الخاصة: فيديو MP4/WebM، ملزمة PDF، وإجابة ملفية آمنة.
- الاختبارات: اختيار من متعدد، صح/خطأ، إجابة نصية، وإجابة ملفية.
- الموضوعي يصحح آلياً، والمقالي يراجعه المدرس، ولا تظهر الإجابات الصحيحة قبل إصدار النتيجة.

## الإعدادات

- إعدادات عامة يديرها المدير: اسم المنصة، المنطقة الزمنية، وحالة رسالة الصيانة الأساسية.
- تفضيلات شخصية: السمة، تقليل الحركة، واللغة العربية الافتراضية.
- لا تُضاف قنوات إشعار أو بيانات اتصال أو خصائص تشغيلية غير مطلوبة قبل قرار منتج صريح.

## المسار الثانوي

رحلة التعلم عرض بديل مستقبلي لنفس الدروس المنشورة، وليست قاعدة بيانات أو تطبيقاً منفصلاً. قبل التسليم يكفي تثبيت عقد إسقاط خفيف يسمح بترتيب الدروس كعُقد تقدم. المساعد الذكي مؤجل ولا يجوز أن يؤخر المسار الأساسي.

## خارج V1

- هيكل مدرسة وموظفون تابعون لها.
- ولي أمر، مشرف أكاديمي، سوق، دفع إلكتروني، دردشة، حضور، وجدول حصص.
- مساعد ذكي فعلي أو لعبة كاملة داخل رحلة التعلم.
- أي واجهة جديدة قبل بوابة النقاش الإلزامية في المرحلة الرابعة.
