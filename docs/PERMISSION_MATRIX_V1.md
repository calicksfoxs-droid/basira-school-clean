## قاعدة المدير

المدير جهة تشغيل ورقابة للمنصة، لذلك يمكنه الوصول إلى الموارد عند الحاجة الإدارية. لا تمنحه الواجهة افتراضياً شاشات ازدحام يومية، لكن RLS وطبقة البيانات لا تمنع الرقابة المصرح بها.

## قاعدة المدرس

لا تكفي صفة `teacher`. كل عملية على مادة أو مجموعة أو وحدة أو درس أو اختبار أو تسليم تتحقق من سلسلة الملكية حتى `teacher_id`.

## قاعدة الطالب

الوصول يتطلب: جلسة حالية + حساب نشط + عضوية مجموعة نشطة + مادة/درس منشور. معرفة UUID لا تمنح وصولاً.
